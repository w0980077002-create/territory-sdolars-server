# Territory G123 — Arena Stability & Anti-Duplicate

## База
G122 Arena Gameplay Polish. G123 меняет только серверный Arena-контур и Cloudflare migration; город/PvE/экономика не менялись.

## Что сделано
- Reconnect: повторное WebSocket-подключение восстанавливает текущий бой или очередь без создания второго игрока.
- Запрещено повторно вставать в очередь, пока Telegram ID уже находится в активном бою.
- Каждое действие боя получает `actionId`; повторная отправка того же действия игнорируется.
- Для каждого хода введён `turnSeq`; старые/повторные ходы отклоняются сервером.
- Сервер проверяет владельца хода, цель, защитные зоны и допустимые значения перед расчётом.
- Таймаут хода — 45 секунд; просроченный ход сервер пропускает.
- Завершённые комнаты очищаются после 15 минут, чтобы Durable Object не накапливал мусор.
- Награда Arena стала идемпотентной: одна награда на пару `room_id + telegram_id` в TerritoryDB.
- Reconnect получает `reconnect_state` с текущим room/turnSeq/activeId.
- Персональный результат сохраняется: игрок получает «Победа» только если его команда победила.
- Сохраняется правило выхода: вышедший игрок не может вернуться в тот же бой.
- Chaos остаётся только для реальных игроков; 1×1/3×3 используют серверное заполнение ботами.

## Cloudflare
Добавлена migration `v5` для Durable Object `RoomHub`:
`new_classes = ["RoomHub"]`.

Существующие secrets/bindings не заменяются. `BOT_TOKEN`, `ADMIN_PASSWORD` и остальные secrets сохраняются.

## API contract для клиента
Для атаки клиент должен отправлять:
- `type: "attack"`
- `actionId`: уникальная строка на попытку действия
- `turnSeq`: значение из последнего `room_start` / `state` / `reconnect_state`
- `targetId`
- `defense`: массив из `head`, `chest`, `waist`, `legs`
