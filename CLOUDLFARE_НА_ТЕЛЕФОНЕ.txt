TERRITORY — SDOLARS s30

Это версия, подготовленная специально для простого развёртывания Cloudflare.
В отличие от s29, здесь нет отдельной папки public и отдельного server.js: игра встроена прямо в Worker.

ВАЖНО: токен Telegram-бота НЕ отправляйте в ChatGPT.

Вариант для телефона (через GitHub + Cloudflare):
1. Распакуйте s30.
2. На GitHub создайте новый приватный репозиторий, например territory-sdolars.
3. Загрузите в корень только 3 файла: worker.js, wrangler.jsonc, package.json.
4. В Cloudflare откройте Workers & Pages -> Create application -> Import a repository.
5. Подключите GitHub и выберите этот репозиторий.
6. Build command: npm install && npx wrangler deploy
7. Deploy. Cloudflare создаст workers.dev адрес.
8. После деплоя: Worker -> Settings -> Variables and Secrets -> Add -> Secret.
   Name: TELEGRAM_BOT_TOKEN
   Value: токен вашего Telegram-бота.
9. После сохранения секрета перезапустите Deploy.
10. Откройте https://ВАШ-WORKER.workers.dev/api/health — должно показать ok:true и version:s30.

Если Cloudflare попросит выбрать production branch, выберите main.

После получения workers.dev адреса пришлите его сюда — я подготовлю следующий шаг для Telegram Mini App.
