# Territory — Sdolars s36

Чистая тестовая версия, готовая для GitHub Pages.

## Запуск
Загрузить `index.html` и `.nojekyll` в корень репозитория, включить GitHub Pages для ветки `main` / root и открыть выданный адрес с телефона.

## Работает
- вертикальный полноэкранный мобильный интерфейс;
- живая сцена и анимация персонажей;
- атака с выбором 5 зон;
- защита ровно 2 зон;
- урон, HP, победа и награда;
- сохранение `territory_save` в localStorage;
- нижняя навигация Territory;
- Sdolars;
- казино отсутствует.

Важно: это отдельная тестовая база и она НЕ заменяет старый рабочий репозиторий.
